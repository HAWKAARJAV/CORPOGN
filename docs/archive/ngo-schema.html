9 · State Store — lib/ngo-store.ts

🔄 loadState(ngoId, name, email, score)

  • Checks localStorage[ngo_shared_state_{id}]
  • Returns parsed JSON if exists
  • Falls back to defaultState()
  • SSR-safe: returns default if window undefined

💾 saveState(ngoId, state)

  • Writes to localStorage
  • Dispatches StorageEvent for tab sync
  • SSR-safe guard
  • Used on every doc upload or milestone change

🧮 computeTrustScore(docs)

  • Starts at 15 (base)
  • Adds weight for each uploaded/verified doc
  • Caps at 100
  • Called on every doc state change

📡 Cross-tab sync

  • window.addEventListener("storage", …) in useEffect
  • Re-loads state when another tab saves
  • Production: replace with Supabase Realtime
  • All role dashboards share same ngoId key
