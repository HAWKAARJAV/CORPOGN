Entity Relationships

auth_users ①→◯ corporates
One auth user owns one corporate account (account_type = "corporate")
auth_users ①→◯ ngos
One auth user owns one NGO account (account_type = "ngo")
auth_users ①→◯{ corporate_employees
One auth user can be a corporate employee (account_type = "corporate_employee")
auth_users ①→◯{ ngo_members
One auth user can be an NGO member (account_type = "ngo_member")
corporates ①→◯{ corporate_employees
One corporate has many employee sub-accounts with page-level access
corporates ①→◯{ corporate_messages
One corporate has many admin chat messages
corporates ①→◯{ budgets
One corporate has one budget per financial year
ngos ①→◯{ ngo_members
One NGO has many team members with role-based sidebar access
ngos ①→◯{ ngo_compliance_docs
One NGO has many compliance documents (12A, 80G, CSR-1, etc.)
corporates ①→◯{ project_connections
One corporate can assign multiple projects to different NGOs
ngos ①→◯{ project_connections
One NGO can have multiple project connections (typically one at a time)
project_connections ①→◯{ ngo_project_messages
NEW: Each project connection has a bi-directional chat thread
budgets ①→◯{ fund_allocations
One annual budget is split into multiple campaign allocations
budgets ①→◯{ fund_disbursements
Budget tracks all tranches released / utilized against milestones
